# PadBridge

同じネットワークにある iPad から Mac をミラーリングで操作し、iPad から Mac の Typeless で音声入力するためのアプリです。

- **PadBridge Host** (Mac): メニューバーに常駐し、画面を iPad に配信して、iPad からの操作を Mac に流し込みます。
- **PadBridge** (iPad / iPhone): Mac の画面を全面に映し、タッチ・ポインタ・キーボードの操作と、Typeless の開始・完了を Mac に送ります。
- **PadBridgeKit**: 両者で共有する通信・映像・入力変換のライブラリです。

Mac にはドライバも追加の設定も入れません。Mac 側で必要なのは、アプリ単位の許可 (ローカルネットワーク・画面収録・アクセシビリティ) だけです。

> [!WARNING]
> ペアリングも暗号化もしません。同じ LAN にいる機器なら、どれでも Mac の画面を見て操作できます。信頼できるネットワークでだけ使ってください。

## 必要なもの

- macOS 26 以降の Apple Silicon Mac と、iPadOS 26 以降の iPad
- Mac の [Typeless](https://www.typeless.com/) (音声入力に使う場合)
- Xcode 26
- [Nix](https://nixos.org/) (flake で XcodeGen をこのリポジトリの中だけに用意します)
- [just](https://github.com/casey/just)

## セットアップ

1. `Config/Local.xcconfig.example` を `Config/Local.xcconfig` にコピーし、自分の Apple Developer のチーム ID を書きます。
2. `just run-host` で Mac 側をビルドして起動します。メニューバーに iPad のアイコンが出ます。
3. メニューを開き、「画面収録」と「アクセシビリティ」を許可します。初回は「ローカルネットワーク上のデバイスを見つける」許可も求められるので、許可します。画面収録は、許可したあとにメニューの「再起動」が必要なことがあります。
4. iPad を Xcode とペアリングし (USB で一度つなぎ、デベロッパモードを有効にする)、`xcrun devicectl list devices` で ID を調べて `just install-pad <ID>` で入れます。無料の開発者アカウントの場合は、iPad の「設定 → 一般 → VPN とデバイス管理」でデベロッパ App を信頼します。
5. iPad で PadBridge を開くと、前回つないだ Mac か、見つかった Mac が 1 台だけならそこへ自動でつながります。
6. 蓋を閉じた Mac で iPad のマイクを使う場合は、Mac の「システム設定 → プライバシーとセキュリティ → 画面とシステムオーディオの録音」で、次の 2 つを許可します。
   - 「PadBridge Host」: 初めて iPad をつないだときにダイアログが出るので、許可します。
   - 「Typeless」: 自動では一覧に載らないので、「システムオーディオ録音のみ」の「＋」で加えます。macOS は、このデバイスを読むアプリにもこの許可を求めるためです。足りないときは、iPad で話した直後に iPad に知らせが出て、Mac でこの設定画面が開きます。
   - iPad 側では、初めて Typeless ボタンを押したときにマイクの使用を許可します。
7. 蓋を閉じたまま使う場合は、メニューの「ログイン時に起動」を入れておくと、Mac を再起動したあとも Host が立ち上がり、iPad からつなげます。

## 操作

| iPad での操作 | Mac での動作 |
|---|---|
| 1 本指タップ | クリック (続けてタップするとダブルクリック) |
| 1 本指で払う / 2 本指で動かす / トラックパッドやマウスのスクロール | スクロール (指を離したあとは慣性で流れる) |
| 長押ししてから動かす | ドラッグ |
| 長押しして動かさずに離す / 2 本指で短くタップ | 右クリック |
| 2 本指で広げる・縮める | iPad の上で Mac の画面を拡大・縮小 (5 倍まで。広げながら動かすと見る位置も動く。縮めきると等倍に戻る) |
| 3 本指で左右に払う | 操作スペース (デスクトップや全画面アプリ) の切り替え (左へ払うと右隣へ) |
| 3 本指で上へ払う | Mission Control (もう一度上へ払うか esc で閉じる) |
| 3 本指で下へ払う | アプリケーションウインドウ |
| 画面の下端から上へ払う | Mac の Dock を出す (iPad で Dock を出すのと同じ操作) |
| トラックパッドやマウスのクリック | そのままクリック (副ボタンは右クリック) |
| トラックパッド・マウス・Apple Pencil のホバー | カーソル移動 |
| ハードウェアキーボード | そのままキー入力 (Command などとの組み合わせも可。⌘ を押しながらタップすると ⌘クリック)。押し続けると、Mac のキーのリピートの設定どおりに繰り返します |

### 画面の構成

Mac の画面は全面に表示し、操作は次の 2 か所にまとめています。

- **操作パネル**: 画面の隅に浮かぶ小さなカプセルです。ドラッグで好きな隅へ動かせ、位置は覚えておきます。
  - Enter: Mac の Return キーです。Typeless で話したあと、キーボードを出さずにそのまま送れます。
  - Typeless (マイク): Mac の Typeless の音声入力を開始・完了します。
  - キーボード: ソフトウェアキーボードを出し入れします。
  - アプリ切替: Mac の Command+Tab です。タップするたびに次のアプリへ進み、1 秒タップしないと確定します。
  - その他 (…): Mac の音を iPad で鳴らす (入・切)、切断。
- **特殊キーの列**: キーボードを出している間だけ、そのすぐ上に出ます。
  - esc・Tab
  - 修飾キー ⌃ ⌥ ⌘ ⇧: 押すと次の 1 回 (キー・クリック・ドラッグ) にだけ効き、続けて 2 回押すと固定されます。
  - 矢印 ←↓↑→: 押し続けると繰り返します。
  - 英数・かな: Mac の日本語入力を切り替えます。
  - ー: 長音です。英字配列のキーボードでは - が記号の面にしかないので置いています。英数モードでは - になります。

キーボードで打ったキーは、そのまま Mac に送ります。日本語は Mac 側の日本語入力で変換するので、物理キーボードを Mac につないでいるのと同じ感覚で打てます。かなモードでは - , . / ! ? が「ー」「、」「。」「・」「！」「？」になります。削除キーは押し続けると繰り返し消せます。キーボードを出すと Mac の画面はキーボードの上に縮み、打っている場所が隠れません。

### Typeless で音声入力

操作パネルの **Typeless** ボタンで、Mac の Typeless の音声入力を開始・完了します。

- **タップ**すると開始し、もう一度タップすると完了します。
- **押している間**だけ話し、離すと完了する使い方もできます。

Mac は Typeless の設定ファイル (`~/Library/Application Support/Typeless/app-settings.json`) に書かれたショートカットを読み、それを 1 回押します。ショートカットの設定は読むだけで、書き換えません。Typeless が動いていなければ起動し、ショートカットを受け付けるようになってから押します。前の聞き取りを文字にしている途中で受け付けられなかったときは、押し直します (その間の声も Mac でためておくので、話し始めは落ちません)。

話す声は **iPad のマイク** で拾います。Mac は蓋を閉じると内蔵マイクがハードウェアで切り離されるので、閉じたままでも話せるようにするためです。

- iPad がつながっている間だけ、Mac に入力デバイス「PadBridge iPad マイク」が現れます。Mac に何もインストールせず、macOS の標準の仕組み (プロセスタップと集約デバイス) で作り、iPad の接続が切れると消します。
- iPad をつないだとき、Typeless のマイクが「自動検出」なら、Host が「PadBridge iPad マイク」に設定し、Typeless を起動し直します。このデバイスは macOS の決まりで Mac の既定の入力になれず、「自動検出」のままでは使われないためです。Typeless は選んだマイクがないときは自動検出に戻るので、iPad がつながっていないときの使い方は変わりません。iPad がつながっていても、iPad から話していない間は Mac の既定の入力の音をこのデバイスに流すので、Mac で直接 Typeless を使えます。Typeless で特定のマイクを選んでいる場合は、それを変えません。
- 初めて使うとき、Mac で「PadBridge Host」に「システムオーディオの録音」を許可します。許可がない間は iPad の声を Mac で鳴らさず、Mac 側のマイクで聞き取ります。
- Typeless がこのデバイスを読むには、Typeless にも「システムオーディオの録音」の許可が要ります (macOS の決まり)。システム設定の「プライバシーとセキュリティ」→「画面とシステムオーディオの録音」の「システムオーディオ録音のみ」に Typeless を加えてください。足りないときは iPad に知らせが出ます。
- iPad のマイクで話している間は、Typeless ボタンの周りの輪が声の大きさに合わせて太くなります。iPad が声を拾っているかを確かめられます。
- iPad 側でマイクを許可していない場合も、Mac 側のマイクで聞き取ります。

ボタンの色は、Mac の Typeless が実際に聞き取っているか (Typeless がマイクを使っているか) に合わせます。Mac で直接 Typeless を使ったときや、Typeless の ✕ で取り消したときも、iPad の表示はずれません。iPad が裏に回ったり切断したりしたときに止めるのは、iPad から始めた聞き取りだけです。

### Mac の音

「…」の「Mac の音を iPad で鳴らす」を入れると、Mac で鳴っている音を iPad で鳴らします。選んだ設定は覚えておき、次につないだときも使います。

- 鳴らしている間は、Mac のスピーカーからは鳴りません。iPad アプリを裏に回したり、この設定を切ったり、接続が切れたりすると、Mac で鳴るように戻ります。iPad をしまったまま Mac を開いても、Mac が無音のままになりません。
- iPad のマイクで Typeless に話している間は鳴らしません。iPad で鳴らした Mac の音を、マイクが拾わないようにするためです。
- 何も鳴っていない間は送らないので、通信量と iPad の電池は使いません。
- Mac で「PadBridge Host」に「システムオーディオの録音」の許可が要ります (iPad のマイクと同じ許可です)。

### 接続の維持

iPad で別のアプリに切り替えても、接続は切れません。裏にいる間は映像だけを止め、前面に戻るとすぐに再開します。Wi-Fi の瞬断などで切れた場合も、その場で自動的につなぎ直します。

Mac の解像度を変えたり、メインディスプレイが変わったりしたときは、映像をその画面に合わせて作り直します。

## 開発

```sh
just test   # PadBridgeKit の単体テスト (通信、H.264 の符号化から復号、タッチの読み替え、キーの並びとリピート、修飾キー、Typeless のショートカットの解釈と押すかどうかの判断、Mac の音をためて左右に分けて鳴らす処理)
```

検証は、単体テストとビルドで行います。使っている Mac や iPad のマウス・キー・窓を動かしたり、利用者の操作を見張ったりする検証はしません。

## 既知の制約

- 送れる画面は Mac のメインディスプレイだけです。
- ハードウェアキーボードの Command+Tab など、iPadOS が先に受け取るショートカットは Mac に届きません。アプリの切り替えはバーのボタンを使います。
