# PadBridge

同じネットワークにある iPad から Mac をミラーリングで操作し、iPad のマイクで Mac に音声入力するためのアプリです。

- **PadBridge Host** (Mac): メニューバーに常駐し、画面を iPad に配信して、iPad からの操作と文字を Mac に流し込みます。
- **PadBridge** (iPad / iPhone): Mac の画面を映し、タッチ・ポインタ・キーボード・音声入力の操作を Mac に送ります。
- **PadBridgeKit**: 両者で共有する通信・映像・入力変換のライブラリです。

Mac には仮想オーディオデバイスなどのドライバを入れません。音声認識は iPad の中で行い、確定した文字だけを Mac の入力カーソル位置に挿入します。Mac 側で必要なのは、アプリ単位の許可 (ローカルネットワーク・画面収録・アクセシビリティ) だけです。

## 必要なもの

- macOS 26 以降の Apple Silicon Mac と、iPadOS 26 以降の iPad
- Xcode 26
- [Nix](https://nixos.org/) (flake で XcodeGen をこのリポジトリの中だけに用意します)
- [just](https://github.com/casey/just)

## セットアップ

1. `Config/Local.xcconfig.example` を `Config/Local.xcconfig` にコピーし、自分の Apple Developer のチーム ID を書きます。
2. `just run-host` で Mac 側をビルドして起動します。メニューバーに iPad のアイコンが出ます。
3. メニューを開き、「画面収録」と「アクセシビリティ」を許可します。初回は「ローカルネットワーク上のデバイスを見つける」許可も求められるので、許可します。画面収録は、許可したあとにメニューの「再起動」が必要なことがあります。
4. iPad を Xcode とペアリングし (USB で一度つなぎ、デベロッパモードを有効にする)、`xcrun devicectl list devices` で ID を調べて `just install-pad <ID>` で入れます。
5. iPad で PadBridge を開き、一覧に出た Mac を選んで、Mac のメニューに表示されているペアリングコードを入力します。コードは iPad のキーチェーンに保存されるので、入力は初回だけです。

## 操作

| iPad での操作 | Mac での動作 |
|---|---|
| 1 本指タップ | クリック (続けてタップするとダブルクリック) |
| 1 本指で動かす (長押ししてから動かしてもよい) | ドラッグ |
| 長押しして動かさずに離す / 2 本指で短くタップ | 右クリック |
| 2 本指で動かす / トラックパッドやマウスのスクロール | スクロール |
| トラックパッドやマウスのクリック | そのままクリック (副ボタンは右クリック) |
| トラックパッド・マウス・Apple Pencil のホバー | カーソル移動 |
| ハードウェアキーボード | そのままキー入力 (Command などとの組み合わせも可) |

画面下のバーには、esc・Tab・削除・Return のボタンと、文字を打って送る入力欄があります。入力欄では iPad のソフトウェアキーボードや、キーボードの音声入力も使えます。

### 音声入力

マイクボタンを**押している間**、iPad のマイクで聞き取り、離すと認識した文字を Mac のカーソル位置に入力します。**短くタップ**すると聞き取りを続け、もう一度押すと入力します。初回は音声認識モデルのダウンロードが入ります。

## 開発

```sh
just test   # PadBridgeKit の単体テスト (TLS-PSK のループバック通信、H.264 の符号化から復号までを含む)
just e2e    # 実際の Host を起動し、iPad 役のクライアントで発見・映像・クリック・スクロール・キー・文字入力を確かめる
```

`just e2e` は、Host をターミナルから直接起動して、ターミナルの画面収録・アクセシビリティ権限を引き継がせます。テスト用の Host は別の Bonjour 名で動くので、普段使いの Host を起動したままでも実行できます。

実行中の数秒間、カーソルと最前面の窓を使います。日本語入力モードの検証では、入力ソースが日本語でなければテスト中だけ切り替え、終わったら元に戻します。

## 既知の制約

- 送れる画面は Mac のメインディスプレイだけです。
- Command+Tab など、iPadOS が先に受け取るショートカットは Mac に届きません。
- Mac の音は iPad に送りません。
- アクセシビリティ経由で文字を挿入できないアプリ (Electron 製など) では、キー入力として文字を送ります。Mac が日本語入力モードでも、変換されずにそのまま入ることを確かめています。
