# PadBridge

同じネットワークにある iPad から Mac をミラーリングで操作し、iPad から Mac の Typeless で音声入力するためのアプリです。

- **PadBridge Host** (Mac): メニューバーに常駐し、画面を iPad に配信して、iPad からの操作を Mac に流し込みます。
- **PadBridge** (iPad / iPhone): Mac の画面を映し、タッチ・ポインタ・キーボードの操作と、Typeless の開始・完了を Mac に送ります。
- **PadBridgeKit**: 両者で共有する通信・映像・入力変換のライブラリです。

Mac にはドライバも追加の設定も入れません。Mac 側で必要なのは、アプリ単位の許可 (ローカルネットワーク・画面収録・アクセシビリティ) だけです。

> [!WARNING]
> ペアリングも暗号化もしません。同じ LAN にいる機器なら、どれでも Mac の画面を見て操作できます。信頼できるネットワークでだけ使ってください。

## 必要なもの

- macOS 26 以降の Apple Silicon Mac と、iPadOS 26 以降の iPad
- Mac の [Typeless](https://www.typeless.com/) (音声入力に使う場合)
- Xcode 26
- [Nix](https://nixos.org/) (flake で XcodeGen をこのリポジトリの中だけに用意します)
- [just](https://github.com/casey/just)

## セットアップ

1. `Config/Local.xcconfig.example` を `Config/Local.xcconfig` にコピーし、自分の Apple Developer のチーム ID を書きます。
2. `just run-host` で Mac 側をビルドして起動します。メニューバーに iPad のアイコンが出ます。
3. メニューを開き、「画面収録」と「アクセシビリティ」を許可します。初回は「ローカルネットワーク上のデバイスを見つける」許可も求められるので、許可します。画面収録は、許可したあとにメニューの「再起動」が必要なことがあります。
4. iPad を Xcode とペアリングし (USB で一度つなぎ、デベロッパモードを有効にする)、`xcrun devicectl list devices` で ID を調べて `just install-pad <ID>` で入れます。無料の開発者アカウントの場合は、iPad の「設定 → 一般 → VPN とデバイス管理」でデベロッパ App を信頼します。
5. iPad で PadBridge を開くと、前回つないだ Mac か、見つかった Mac が 1 台だけならそこへ自動でつながります。

## 操作

| iPad での操作 | Mac での動作 |
|---|---|
| 1 本指タップ | クリック (続けてタップするとダブルクリック) |
| 1 本指で払う / 2 本指で動かす / トラックパッドやマウスのスクロール | スクロール (指を離したあとは慣性で流れる) |
| 長押ししてから動かす | ドラッグ |
| 長押しして動かさずに離す / 2 本指で短くタップ | 右クリック |
| 3 本指で左右に払う | 操作スペース (デスクトップや全画面アプリ) の切り替え (左へ払うと右隣へ) |
| 3 本指で上へ払う | Mission Control (もう一度上へ払うか esc で閉じる) |
| 3 本指で下へ払う | アプリケーションウインドウ |
| トラックパッドやマウスのクリック | そのままクリック (副ボタンは右クリック) |
| トラックパッド・マウス・Apple Pencil のホバー | カーソル移動 |
| ハードウェアキーボード | そのままキー入力 (Command などとの組み合わせも可。⌘ を押しながらタップすると ⌘クリック) |

画面下のバーには、次のボタンと、文字を打って送る入力欄があります。

- esc・Tab・削除・Return
- 矢印キー ←↑↓→ (削除と矢印は押し続けると繰り返します)
- 修飾キー ⌘ ⌥ ⌃ ⇧: 押すと次の 1 回 (キー・クリック・ドラッグ) にだけ効きます。続けて 2 回押すと固定され、もう一度押すと外れます。⌘ を押してから「キーボード」で c を打てば ⌘C です。
- アプリ切替: Mac の Command+Tab です。タップするたびに次のアプリへ進み、1 秒タップしないと確定します。
- キーボード: ソフトウェアキーボードを出し、打った文字を 1 文字ずつそのまま Mac に送ります。英数字と空白はキーとして、記号や日本語は文字として送ります。日本語を変換してから送りたいときは、右の入力欄を使います。

### Typeless で音声入力

バーの **Typeless** ボタンで、Mac の Typeless の音声入力を開始・完了します。

- **タップ**すると開始し、もう一度タップすると完了します。
- **押している間**だけ話し、離すと完了する使い方もできます。

Mac は Typeless の設定ファイル (`~/Library/Application Support/Typeless/app-settings.json`) に書かれたショートカットを読み、それを 1 回押します。Typeless の設定は読むだけで、書き換えません。録音は Mac 側のマイクで行います。

### 接続の維持

iPad で別のアプリに切り替えても、接続は切れません。裏にいる間は映像だけを止め、前面に戻るとすぐに再開します。Wi-Fi の瞬断などで切れた場合も、その場で自動的につなぎ直します。

## 開発

```sh
just test   # PadBridgeKit の単体テスト (通信、H.264 の符号化から復号、タッチの読み替え、キーの並び、修飾キー、Typeless のショートカットの解釈)
```

検証は、単体テストとビルドで行います。使っている Mac や iPad のマウス・キー・窓を動かしたり、利用者の操作を見張ったりする検証はしません。

## 既知の制約

- 送れる画面は Mac のメインディスプレイだけです。
- ハードウェアキーボードの Command+Tab など、iPadOS が先に受け取るショートカットは Mac に届きません。アプリの切り替えはバーのボタンを使います。
- Mac の音は iPad に送りません。
- Typeless の聞き取り状態を Mac から読み取っていないので、Mac 側で ✕ を押して取り消した場合などは、iPad のボタンの表示がずれます。もう一度タップすれば合います。
